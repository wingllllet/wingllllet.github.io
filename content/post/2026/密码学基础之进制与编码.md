## 前言

## 进制

​	进制，我们平常生活中最常用的进制就是十进制。十进制也是我们从小学就开始学习的，可以说它已经成了我们生活的一部分，话句话说人与人之间的交流默认依靠的就是十进制。但是在计算机领域中，它们认识的进制则是010这样的二进制，进而为十六进制。那么二进制，十六进制与十进制比有什么区别吗？答案是没有区别。十进制是遇十进一，它一位中最大数字就是9，再加1就会向第二位增加。相当于`0...09+0...01=0...10`。顾名思义二进制与十六进制一个是遇二进一，一个则是遇十六进一。

​	那么他们之间又如何转化呢。以二进制与十进制之间的转化为例，弄懂了这个像什么八进制，十六进制就能融会贯通。现在有这么一串二进制数字`100110`，按从右到左，分别为`1, 2, 4, 8, 16, 32`。那么只要把对应位置的数字拿过来相乘即可`1*32+0*16+0*8+4*1+2*1+0*1=38`所以该二进制数字转化为十进制就是`38`。

​	现在有一个十六进制`6a4d`，与二转十一样，现从右往左数以次表示`1, 16, 256, 4096`，那么转为十进制就是`d*4096+4*256+a*16+6*1=27213`。其实从这里我们就可以得到一个转化规则
$$
现在一个数N是x进制：N_x=abcde,
用向量表示N_x=(a,b,c,d,e)\\
x进制转化为十（d）进制的规则可表示为一个函数\\
N_d=f_x(a,b,c,d)=a\cdot x^4+b\cdot x^3+c\cdot x^2+d\cdot x^1 + e
$$
 	不知道有没有发现在十六进制中超过十的数字就开始使用字母代替了，其实这也是为了方便以及可观，如果使用两位数字来表示十六进制比如`d(257)=x(16, 01)`，不能每次表示十六进制都用向量的方式吧，并且一位数字不使用字母的情况下最大是9，两位则是99。而十六进制最多只用16，那么剩下的83就会被浪费了，所以在十六进制中我们使用字母来表示d(10)以后的数字。

​	二进制与十六进制之间转换就更简单了，大家知道`16=2^4`那么四位二进制就可以表示一位十六进制。所以十六进制在计算机中作用也是非常大的。

## 编码

​	进制讲完了，但我们还有一个疑惑，既然计算机只看得懂010传输也是010，那么信息和数字之间又是如何转化的呢？

​	这时候就需要编码出场了，大家可能听说过base64编码，摩斯电码，佛曰以及一些奇奇怪怪的编码，但其实性质都是一样的，它们无非是一个双射函数，能够将一个字符以某种固定规则转换成另一个字符（或图案，或奇奇怪怪的东西）。双射函数又称之为置换，置换密码又可以看作以表为密钥的编码。

​	由于这种编码规则有许许多多中，这里只讨论公认的编码规则`ASCII码`![img](https://pub-491d983cd40449fea50cff8b66683e0d.r2.dev/img/{fullName}/20261017093746123.jpg)![img](https://pub-491d983cd40449fea50cff8b66683e0d.r2.dev/img/{fullName}/20261017093743740.gif)

​	上图就是完整的ASCII码表一共256个字符，因为一个字节是8比特，所以一共有`2^8=256`种可能，不过可见字符只有33-126。不过我们不用每次都对照表来找数字字符，在python里我们可以使用`chr`和`ord`来实现字符数字的转换。

```python
print(ord("f"))
print(chr(102))

# 102
# f
```

​	现在我们可以把进行字符与数字的互转了，那么对一个字符串呢？既然字符串是一个字符一个字符拼接而成的，我们也可以把数字拼接起来`flag就可以转为10210897103`。不过在十进制中有的两位有的三位，为了更好表示我们可以对不满足三位的前面添一个`0`这样就变成了`102108097103`可是一个三位的十进制最大是`999`而`ASCII码`最大只有256，就像上面讲的，这样会浪费很多空间。仔细观察256，你会发现它不就是16的二次方，所以我们就可以用两位十六进制来表示，所以`flag`就可以表示为`666c6167`在转成十进制`1718378855`。现在我们就可以构造字符串和数字互相转化的代码了

```python
def bytes_to_long(text):
    result = 0
    text = text[::-1]
    for index in range(len(text)):
        char_hex = hex(ord(text[index])).replace('0x', '')
        result += int(char_hex, 16) * 256 ** index
    return result

def long_to_bytes(number):
    result = ""
    number = hex(number)[2:]
    hex_pairs = [number[start:start+2] for start in range(0, len(number), 2)]
    for hex_pair in hex_pairs:
        result += chr(int(hex_pair, 16))
    return result
```

​	不过大家也看到了改代码十六进制转字符串时操作的是字符类型，但是十六进制是数字，那么我要如果操作数字来进行转化呢。这时就要引入密码学中常用的运算方法`整除(//)`和`取余(%)`。以`N = 123456`为例，如果我们只想要得到末尾的`6`该怎么办，只需要取余10即可`123456 // 10 = 6`，那么取56则是取余100，可以发现我们想取末尾几位只需要取余它的进制数与位数的乘积即可。那换个想法我们只想抛弃末尾的6呢？只需要对10整除`123456 % 10 = 12345`可以发现都是对它的进制数进行运算。那么是不是十六进制也可以这样使用？现在有一个十六进制`abcdef`只取`f`按之前的规律我们应该取余16。现在运算一下
$$
(x)abcdef = (d)11259375\\
(d)11259375 / 16 =(d)15=(x)f
$$
可见对仍以进制都可以这样做，那么我们的代码就可以修改一下

```python
def long_to_bytes(number):
    result = ""
    while number != 0:
        result += chr(number % 256)
        number //= 256
    return result[::-1]
```

## 字节

​	如果说字符是我们人类认识的符号，字节就是计算机认识的符号。它是计算机体系结构中用于表示数据存储、传输和寻址的基本单位，可以表示256个不同的值，是最小的数据单元。在python中`b'f'`就表示一个字节。在密码学中它会非常常见，因为现代密码学算法只处理字节（八位组）

## base64编码

​	base64编码也是非常常见的编码了。之前ctf比赛中也是经常使用它，这次就来详细的解释一下它是如何怎么编码的。有没有考虑过为什么它叫base64，这个64是从何而来。之前我们提到编码说白了就是以表为密钥的置换密码，而它的表中只含有`a-z A-Z 0-9 + / =`加起来刚好64个字符这就是64的来源。一个字节有256中也就是两个十六进制。它要如何表示每一个字节呢？仔细想想64就是2的六次方，所以我们是不是可以把字节拆开以8个二进制为一组，这样我们就能用base64表来分别表示了。这就是base64编码的原理。举个例子 `flag`我们把它编码一下。

```
flag = 1100110011011000110000101100111
110011 | 001101 | 100011 | 000010 | 110011 | 100000
不够八位前面补0
00110011 | 00001101 | 00100011 | 00000010 | 00110011 | 00100000
对照base64编码表就是
z N j C z g
```
