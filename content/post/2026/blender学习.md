## 认识blender

### 基础操作

#### 1. 视角的控制

```
旋转视角：鼠标中键
平移视角：shift+鼠标中键
推进推远视角：滚动鼠标中键
```

#### 2. 物体的控制

```
移动物体：G
旋转物体：R
缩放物体：S
恢复变换：Alt+G、Alt+R、Alt+S				ps.如果其他软件的快捷键与该快捷键冲突，很可能导致该快捷键无效

新建物体：Shift+A
复制物体：Shift+D
删除物体：X 或者 Delete

隐藏物体：H
显示隐藏物体：Alt+H
隐藏没有被选中的物体：Shift+H

选择物体 刷选：C  全选：A
按住Shift可以加选或者减选
```

#### 3. 视图的切换

```
7-顶视图，ctrl+7底视图
1-前视图，ctrl+1后视图
3-右视图，ctrl+3左视图
9 反转当前视图

0：切换摄像机的视角
5：切换透视投影的正交投影
2,4,6,8：前后左右角度微调
+，-：缩放微调
```

### 基础工作流

#### 1. 基础步骤

```
建模-布光-材质-渲染
```

#### 2. 重要概念

```
1. 窗口面板可以拆分，可互换
2. 游标可以用来定位和当轴心点
3.每个物体都有原点，在3d世界的计算机眼里，原点就是储存物体信息的数据点
```

#### 3. 面板快捷键

```
调用游标Pie目录：shift+s
游标恢复到世界中心：shift+C
移动游标：游标工具  或者  shift+右键
最大化窗口：ctrl+空格
G移动状态下，按住ctrl，可以一每个方格增量为单位进行吸附
切换全局和局部坐标系：在G移动状态下按两次X，Y，Z
```

## 建模

### 点线面的控制与选择

#### 1. 模式切换

```
切换编辑模式：Tab
切换点线面：1-点模式	 2-线模式   3-面模式
```

#### 2. 点线面的选择

```
选择工具的切换：W
框选：B
刷选：C（滚动鼠标可以改变鼠标大小，右键或者ESC结束刷选状态）
反选：ctrl+I
多选：shift
选择两个元素最短路径：ctrl
选择相连元素：L
循环选择：按住alt+双击，就可以选择一个循环边
垂直方向的循环选择：ctrl alt+双击
随机选择：左上方选择菜单-select random
加选：ctrl+数字键盘加号
减选：ctrl+数字键盘减号
```

#### 3. 点线面的控制

```
移动：G
缩放：S
旋转：R
删除：X（注意删除边和融并边的区别，删除会出现孔洞，融并会把剩下的边连起来）
法相/法线：指始终垂直某平面或者某切面的虚线，用来定义光线如何从曲面反弹的向量
进入透视模式：alt+z
```
