## windows 10 家庭版没有hyper-V服务

新建一个记事本

```cmd
pushd "%~dp0"
dir /b %SystemRoot%\servicing\Packages\*Hyper-V*.mum >hyper-v.txt
for /f %%i in ('findstr /i . hyper-v.txt 2^>nul') do dism /online /norestart /add-package:"%SystemRoot%\servicing\Packages\%%i"
del hyper-v.txt
Dism /online /enable-feature /featurename:Microsoft-Hyper-V-All /LimitAccess /ALL
```

改为`1.cmd`, 右键并以管理员身份运行

## 修改kali的镜像源

​	进入`/etc/apt/`目录，可能以后kali会有更新，导致里面的文件有些不同，但名字大致是相似的。我这里是需要进入`sources.list.d`目录。如果里面的文件是`kali.sources`里面的内容应该是

```bash
# See https://www.kali.org/docs/general-use/kali-apt-sources/
Types: deb
URIs: http://http.kali.org/kali/
Suites: kali-rolling
Components: main contrib non-free non-free-firmware
Signed-By: /usr/share/keyrings/kali-archive-keyring.gpg
```

想要修改镜像源的话，只需要改这一部分。

```
URIs: http://http.kali.org/kali/
```

​	如果里面是`sources.list`文件，在里面需要把内容改为，当然镜像源可也选自己喜欢的

```
deb https://mirrors.aliyun.com/kali kali-rolling main non-free contrib
deb-src https://mirrors.aliyun.com/kali kali-rolling main non-free contrib
```

​	最后在终端输入`sudo apt update`更新配置

## git提交文件出现某一文件怎么都交不上去

​	在使用`git commit -a`提交文件时可能会遇到某一文件怎么都交不上去。报错情况大致如下：

```shell
Changes not staged for commit:
  (use "git add <file>..." to update what will be committed)
  (use "git restore <file>..." to discard changes in working directory)
  (commit or discard the untracked or modified content in submodules)
        modified:   themes/hugo-theme-stack (modified content)
```

​	出现这种情况可能是因为git下来的文件中有.git文件，它不是你的项目里的git,删除下载下来的git项目的git文件即可。

![ScreenShot_2026-08-16_170721_407](https://pub-491d983cd40449fea50cff8b66683e0d.r2.dev/img/{fullName}/20260816170804035.jpg)

​	只需要删除这个`.git`文件即可。
